### Selected work

**NoteBrain AI** — Notes that become the model's context. Ask a question, get an answer drawn only from what you wrote, with a citation that jumps to the exact line. `Next.js` `Supabase` `pgvector` `OpenAI embeddings`

**Owner's Box** — AI-guided whitepaper microsites for small-cap public companies. The compliance guardrail layer is the product: a bot talking to investors either stays inside what was disclosed or creates a securities problem.

**World App mini app** — World ID auth, live balances with dynamic decimals, ERC-20 and native transfers, Uniswap V3 swaps with slippage protection, QR receive, on-ramp handoff. `MiniKit` `viem` `TypeScript`

**Bigfoot AI** — My AI agency, and the outbound system behind it. Prospect data into a classification layer into booking, with webhook-driven reply handling and clean state ownership between systems.

**Browser games** — Three.js and Phaser on a Supabase backend, with profiles, shops, leaderboards and payments. Input is timestamped at the event and judged against a fixed-step clock, so the same swing scores identically on a low-end Android and a flagship.

**Astronova** — Solana launch site in Astro with a full Framer Motion system: scroll reveals, staggered entrances, flip animations, glass surfaces.

### How I think about AI-written code

I build with Claude every day, which means I spend a lot of time fixing what it gets wrong: duplicated styles instead of tokens, skipped accessibility, magic numbers, and structure that drifts after a few rounds of edits. The fix is boring — design tokens at the top of one file, a conventions doc the model reads before it writes, and a human who actually reads the diff.
